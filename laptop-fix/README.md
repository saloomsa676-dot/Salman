# تسريع اللابتوب (Laptop Fix)

تطبّق خطوات التسريع اللي طلعت من تقرير `laptop-check`. **تسألك قبل كل خطوة**، ما تحذف ولا تلغي تثبيت أي برنامج، ما تقفل تطبيق Claude، وما تحتاج صلاحية مدير.

## طريقة التشغيل
1. نزّل ملف **`Laptop-Fix.bat`** (ملف واحد، ما يحتاج فك ضغط).
2. احفظ أي شغل مفتوح.
3. افتح مجلد **Downloads** ← دبل كليك على **`Laptop-Fix`**.
4. إذا ظهرت رسالة "Windows protected your PC" ← **More info** ← **Run anyway**.
5. جاوب على النوافذ اللي تطلع لك (Yes / No).

## الملفات
- `Laptop-Fix.bat` — الملف اللي تشغّله. فيه زر التشغيل والفحص مع بعض.
- `LaptopFix.ps1` — نفس الكود بشكل مقروء (المصدر). إذا عدّلته، أعد بناء `Laptop-Fix.bat` منه.

## وش تسوي بالترتيب
| الخطوة | وش تسوي | تسأل قبل؟ |
|---|---|---|
| 1. node | تعرض مين مشغّل نسخ node الكثيرة (Claude Code أو تطبيق Claude) | لا، قراءة بس |
| 2. المتصفح | تخلي متصفح واحد وتسكّر الثاني، وتفتح لك صفحة Memory Saver | نعم |
| 3. ChatGPT و Notion | تسكّر التطبيقات وتفتحها كتبويبات في المتصفح | نعم |
| 4. بدء التشغيل | توقف التشغيل التلقائي لـ Teams و Edge و Grammarly و ChatGPT و Notion | نعم |
| 5. Restart | تعيد تشغيل الجهاز بعد دقيقة (تقدر تلغيه بـ `shutdown /a`) | نعم |

بعدها تحفظ ملخص بالعربي على سطح المكتب (`Laptop-Fix_<التاريخ>.txt`) فيه: وش تغيّر، وش باقي عليك، وطريقة إرجاع كل شي.

## اللي ما تلمسه
OneDrive، وحماية ويندوز (SecurityHealth)، وتطبيق Claude، وأي برنامج مسجّل لكل المستخدمين (هذا يحتاج صلاحية مدير، فتكتبه لك في الملخص بس).

## الإرجاع
- برامج بدء التشغيل: Ctrl + Shift + Esc ← Startup apps ← كليك يمين ← Enable.
- التطبيقات اللي تسكّرت: افتحها من قائمة Start، ما انحذف شي.
