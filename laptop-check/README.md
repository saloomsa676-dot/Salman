# فحص اللابتوب (Laptop Check)

أداة فحص لويندوز 10 و 11. **تقرأ فقط** — ما تغيّر أي إعداد، ما تحذف أي ملف، وما ترسل أي شي للإنترنت.

## طريقة التشغيل
1. نزّل `Laptop-Check.zip` ← كليك يمين عليه ← **Extract All** (استخراج الكل).
2. افتح المجلد المستخرج ← دبل كليك على **`Run-LaptopCheck.bat`**.
3. إذا ظهرت رسالة زرقاء "Windows protected your PC" ← اضغط **More info** ← **Run anyway**.
4. انتظر دقيقة تقريباً (المراوح بتعلى 20 ثانية وقت اختبار الأداء — طبيعي).
5. التقرير يفتح بالمتصفح تلقائياً، ويتحفظ في مجلد جديد على سطح المكتب اسمه `Laptop-Check_<التاريخ>`.

## وش يفحص
| البند | وش يقيس |
|---|---|
| الشاحن / البطارية | لابتوبات الألعاب تخفّض الأداء على البطارية |
| وضع الطاقة في ويندوز | Best power efficiency / Balanced / Best performance |
| سرعة المعالج تحت الضغط | اختبار 20 ثانية يكشف الخنق (طاقة أو حرارة) |
| الذاكرة RAM | نسبة الاستخدام + أكثر البرامج استهلاكاً + شريحة وحدة أو ثنتين |
| القرص | المساحة الفاضية + صحة القرص + نشاطه بالخلفية |
| المعالج بالخلفية | البرامج اللي تاكل المعالج وأنت ما تسوي شي |
| برامج بدء التشغيل | عددها وأسماؤها |
| برامج الحماية | تعارض برنامجين أو برنامج تجريبي ثقيل (McAfee / Norton) |
| تعريف كرت NVIDIA | عمره |
| إعادة التشغيل | آخر Restart + تحديثات معلّقة |

## الملفات
- `Run-LaptopCheck.bat` — زر التشغيل.
- `LaptopCheck.ps1` — الفحص نفسه (PowerShell). لازم يكون بنفس المجلد مع ملف `.bat`.

الحدود المستخدمة في الحكم (مثل 85% للذاكرة) قواعد عامة، مو أرقام رسمية من Microsoft.
